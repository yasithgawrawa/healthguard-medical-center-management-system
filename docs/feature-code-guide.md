# Feature code lookup

Search the whole workspace with **Ctrl+Shift+F** (Windows/Linux) or **Command+Shift+F** (macOS). Search for a feature followed by ` | `, for example `Add New Medicine | ` or `Book Appointment | `. The exact same name marks its related code segments.

Each comment follows `Feature Name | Layer | Explanation`. JavaScript uses `//`; JSX uses a single-line `{/* ... */}` comment. Shared forms have a separate label for each supported feature.

Follow write flows through **Form → Frontend Validation → Submit Logic → API Request → Route → Backend Validation → Controller → Business Logic → Database Model**. Some features implement business logic in the controller. Read actions and state-change buttons may not have a separate form. Configured forms are marked **Form Configuration** and rendered by the shared OperationPanel.

The links below point to existing code. A dash means that this particular layer has no dedicated segment labeled for the feature.
